Installation

Quick Setup

  1. Upload the plugin files to the /wp-content/plugins/aicc-comments-reply directory
  2. Activate the plugin through the WordPress plugins screen
  3. Go to Settings → AICC OpenAI Comment Reply
  4. Enter your OpenAI API key and configure settings
  5. Start using the "Reply with A.I" button in comments

Requirements

  • WordPress 5.0 or higher
  • PHP 7.4 or higher
  • OpenAI API key (free trial available)

Important Note

The plugin requires an OpenAI API key to function. You can get one from OpenAI's website.
